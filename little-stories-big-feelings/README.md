# Little Stories, Big Feelings

A warm, responsive personal story journal with a public reading site and a private author desk.

- **Public:** home, searchable/category-filtered story archive, unique story pages, About page, share links, and SEO metadata.
- **Author:** password login, rich-text story editor, autosaved private drafts, preview, publish/unpublish/delete, scheduled publishing, cover images, editable site name and About text.
- **Security:** Supabase Auth plus a single-author UUID allowlist, RLS on every table and Storage object, separate private draft and public story tables, and sanitized rich-text JSON rendering.

Start with [SETUP.md](SETUP.md) for Supabase and Vercel setup. The included sample story is intentionally labeled.
